# Actualización C28-Q desde C28-P

Se entregan dos archivos alternativos:

- `Aula_Computadora_C28_Q_GLOBAL_COMPLETO.zip`: **recomendado para probar**.
  Contiene todo el proyecto y no exige tener archivos de versiones anteriores.
- `Aula_Computadora_C28_Q_PARCHE.zip`: únicamente los documentos y scripts
  nuevos/modificados respecto al **global C28-P**, para ahorrar descargas.

Para aplicar el parche sin eliminar ni sobreescribir archivos ajenos, extrae
ambos ZIP por separado y copia el contenido de `Aula-Computadora/` del
parche sobre la carpeta `Aula-Computadora/` de C28-P. Reemplaza
únicamente los archivos homónimos incluidos en el parche. Esta edición
no modifica los maestros Word/PDF C28-G.

## Prueba con un único bloque de PowerShell

Descarga el ZIP **global C28-Q** a la carpeta Descargas y ejecuta el bloque
de `LEEME_C28_H_GLOBAL_COMPLETO.md`: extrae, ejecuta todos los controles,
crea automáticamente `Retroalimentacion_GLOBAL_C28H_*.zip` y abre su
carpeta en el Explorador de archivos.
