# C28-S: cómo recibir los avances C28-R/S

Este lote trae una ruta NAND de ADD/SUB, dos auditores nuevos, un testbench
Icarus, informe de 248 páginas y ocho hojas de contacto del libro.

- **Global recomendado:** `Aula_Computadora_C28_S_GLOBAL_COMPLETO.zip`.
  Incluye todo el proyecto (también el maestro Word/PDF) y se puede probar
  de manera independiente.
- **Parche desde C28-Q:** `Aula_Computadora_C28_S_PARCHE.zip`.
  Solo agrega/reemplaza los archivos enumerados para esta fase. Descomprime
  el global C28-Q y el parche por separado, y copia la carpeta interna
  `Aula-Computadora/` del parche encima de su homónima en C28-Q.

Para **probar cuando regreses**, elige el global C28-S, descárgalo en
`Descargas` y copia completo el bloque PowerShell de
`LEEME_C28_H_GLOBAL_COMPLETO.md`. El bloque descomprime, ejecuta los
controles, genera el ZIP de retroalimentación y abre la carpeta en el
Explorador automáticamente.

**Estado recibido:** 24/24 Windows aprobado. **Nueva meta: 28/28**.
El 87,3 % describe avance editorial estimado, no CPU construida.
